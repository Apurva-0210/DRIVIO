## 1. Product Overview
- **Product Name**: DRIVIO (formerly FleetEase)
- **Description**: Enterprise bus fleet management, live GPS tracking, schedule booking, ticketing, driver management, billing, and corporate charter booking platform.
- **Product Type**: B2B / B2C Web Platform & Fleet Management Portal.
- **Roles**:
  - `Admin`: Full fleet oversight, route creation, scheduling, pricing, user/agent management, revenue dashboards.
  - `Manager`: Fleet operational health, maintenance logs, toll expenses, fuel/vehicle allocation.
  - `Driver`: Assigned trip tracking, route inspection, passenger manifest, seat occupancy, live GPS broadcast.
  - `Agent`: Ticket counter booking, corporate booking reservations, offline customer assistance.
  - `Customer / Corporate`: Bus searching, seat selection map, booking checkout, live bus tracking, booking history, invoice downloads.
- **Environments**:
  - Local Dev Frontend: `http://localhost:3000`
  - Local Dev Backend: `http://localhost:5001` (Note: Port 5000 is occupied on macOS by AirPlay Receiver / ControlCenter)
  - Production / Staging: TBD / On-premise or cloud deploy

## 2. Tech Stack
- **Architecture**: Monorepo with decoupled frontend (`fleetease-web`) and backend (`fleetease-backend`).
- **Frontend**:
  - React 18.2.0 (SPA, React Router v6.16.0)
  - Styling: Tailwind CSS 3.4.17 + Vanilla CSS Variables (`utils/theme.css`, `App.css`) with DRIVIO Palette (`#101B35`, `#246BFD`, `#19C5E8`, `#E6E9F2`)
  - Icons: Lucide React
  - Maps: Leaflet & React-Leaflet 4.2.1, with optional Google Maps JS loader
  - Realtime: `socket.io-client` 4.7.2
- **Backend**:
  - Node.js & Express 4.18.2 (REST API & WebSockets)
  - Realtime: `socket.io` 4.7.2 (GPS telemetry broadcasting & trip tracking)
  - Database: PostgreSQL (direct connection via `pg` 8.11.3 Pool)
  - Auth: JWT (`jsonwebtoken` 9.0.2) + `bcryptjs` 2.4.3
  - PDF Invoicing: `pdfkit`
- **Database Schema**:
  - Initialized via `fleetease-backend/setup_db.js`
  - Tables: `users`, `vehicles`, `routes`, `stops`, `schedules`, `bookings`, `tickets`, `gps_logs`, `bills`, `tolls`, `corporate_requests`, `testimonials`.

## 4. Critical User Journeys (CUJs)
1. **Passenger Search & Booking Flow**:
   Search routes by origin/destination/date -> Select trip -> Interactive seat selection map -> Checkout/Payment -> Booking confirmation & Ticket issuance.
2. **Live Bus Tracking**:
   Customer tracking URL `/track-bus?trip_id=...` -> Realtime GPS position rendering via Socket.IO / Leaflet map -> Next stop calculation & ETA.
3. **Driver Trip Lifecycle & GPS Telemetry**:
   Driver login -> View assigned trips -> Start trip -> Transmit GPS coordinates (`/api/gps/update` & WebSocket broadcast) -> End trip.
4. **Admin Route & Schedule Dispatching**:
   Create route -> Add intermediate stops & fares -> Create vehicle schedule -> Allocate vehicle and driver.
5. **Corporate Charter Booking & Approval**:
   Corporate inquiry submission -> Admin review & approval -> Invoice generation.

## 5. Risk Areas (Impact × Likelihood)
| Risk Area | Impact (1-5) | Likelihood (1-5) | Score (I×L) | Description |
|-----------|--------------|------------------|-------------|-------------|
| **Database Failure Handling** | 5 | 4 | **20** | Unhandled PostgreSQL disconnections cause raw 500 crashes and unhandled Promise rejections across API routes. |
| **SQL Injection / Parameter Sanitization** | 5 | 3 | **15** | Several routes use dynamic SQL strings or unvalidated req.body/params without Zod/Joi validation schemas. |
| **Concurrent Seat Booking / Race Conditions** | 5 | 3 | **15** | Two users selecting the same seat simultaneously may result in double bookings if transactions / row-level locks are not strictly enforced. |
| **Authentication & Role Authorization Leaks** | 4 | 3 | **12** | Some admin routes lack strict JWT verification middleware or role guards. |
| **Port Collision on macOS (5000 vs 5001)** | 3 | 4 | **12** | Port 5000 AirPlay conflict breaks backend connectivity if fallback to 5001 is not enforced consistently. |
| **Frontend Map / GPS Nil-Pointer Exceptions** | 4 | 3 | **12** | If GPS coordinates are null/undefined or invalid strings, Leaflet map crashes the page without an ErrorBoundary. |

## 6. QA Conventions & Standards
- Brand Identity: DRIVIO styling must be strictly preserved (`#101B35`, `#246BFD`, `#19C5E8`, `#E6E9F2`).
- Backend API responses must return structured JSON: `{ success: boolean, data?: any, message?: string, error?: string }`.
